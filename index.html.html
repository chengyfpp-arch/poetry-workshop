📚 雪廬老人聲調舉隅與吟誦常則宗要（兼採曾院士體製論）
一、雪廬老人《聲調舉隅》與《吟誦常則》要義

• 詩與唱之體用：「詩循聲調，唱依樂譜，名雖有岐，其道一也。詩乃唱之精魂，唱乃詩之聲響。」
• 聲調譜符號法： - —：平聲（平聲長吟）
- ｜：仄聲（仄聲短促）
- ▲：黑角，代表「可通融之聲」
- ◎：雙圈，代表「押韻之腳」
• 《吟誦常則》四大核心原則：
1. 平長仄短：平聲字氣度舒緩長吟，仄聲字（上、去）簡明短促。
2. 入聲急促：古代入聲（質、黠、曷、鐸等部字，現代分派三聲）必須急迫短促、戛然而止，不拖長腔！
3. 停應守，聲可變：句中音節頓逗（五言二／三、七言四／三）與句末之停頓必須恪守，不可混亂；而音高可依個人聲線靈活變通。
4. 字調與句變：揭櫫「小借式」與「大借式」之句變奧妙，指出古人聲律富於變化而非死板教條。

二、曾永義教授《近體詩之體製規律》核心學理

• 平仄四大基模：五言為 A(平平平仄仄)、a(平平仄仄平)、B(仄仄平平仄)、b(仄仄仄平平)。七言於平頭加仄仄、仄頭加平平。
• 對與黏的美學辯證：Ab 或 Ba 為「對」（相反衝突）；aA 或 bB 為「黏」（相同延續）。
• 音律美學哲理：一句之中「先和諧而後衝突」，句與句間「先衝突而後和諧」，相生相激，綿延為抑揚曲直之豐富旋律。
• 絕句四源：首尾兩聯（散行）、後半首（首聯對）、前半首（末聯對）、中二聯（全首對）。
• 孤平與拗救：a 句式第一字作仄則犯孤平，逼促窒礙非救不可；對句互救（杜甫促織）與本句自救（高適別韋五）為大師圓融之法。
• 四聲遞換：杜少陵「晚節漸於詩律細」，句中平上去入均勻，句末四聲相間輪轉。

📜 宗師典範作品譜錄（聲調譜與吟唱分析）
雪廬老人 李炳南〈殘燭〉（五絕仄起首句不入韻式典範 ·《浮海集上》）：

未改心腸熱，（｜｜——｜）
全憐暗路人。（——｜｜—◎）
但能光照遠，（｜——｜｜）
不惜自焚身。（｜｜｜——◎）
【雪廬老人原詩正解】（收錄於《雪廬詩集·浮海集上》）：雪公自況名篇，首聯「未改心腸熱，全憐暗路人」以殘燭之熱腸憐憫暗夜行路者；後聯「但能光照遠，不惜自焚身」展現燃燒自己照徹遠方的大悲願力。押平水韻上平十一真韻（人、身），第三字「惜」字為古入聲字（入聲十一陌），短促有力！

杜甫〈促織〉（曾教授講義：對句互救典範）：

促織甚微細，（｜｜｜—｜）
哀鳴何動人。（—— —｜—◎）
【曾教授評析】：出句「甚」拗仄，對句「何」特用平聲，兩相調配互救！

曾永義教授〈寧夏雜詠〉（四聲遞換極致之作）：

巨河九曲竟朝東，【句末平】（上平上入去平平）
多少帝王歌大風。【句末平】（平上去平平去平）
濤沒古今皆綺夢，【句末去】（平入上平平上去）
力征南北盡驚鴻。【句末平】（入平平入去平平）
炎黃李杜雖千古，【句末上】（平平上去平平上）
世道人心未一功。【句末平】（去上平平去入平）
山水幸能消塊結，【句末入】（平上上平平去入）
何如暢快酒杯中。【句末平】（平平去去上平平）
【曾教授自述】：一三五七句末尾字分別為「平、去、上、入」，完美達成四聲遞換！
